# ADR 0001: Gate distribution on source review

## Context

Public access does not automatically grant redistribution rights or make every field appropriate for a curated release.

## Decision

The repository separates portable extraction from release publication. A source receives a documented terms review and privacy checks before a curated artifact can be distributed.

## Consequences

Some historical datasets remain unavailable until their release basis is documented. The local pipeline and source registry still provide reproducible discovery and validation.

## Alternatives considered

Publishing every accessible record would simplify onboarding but could exceed source terms or retain unnecessary identifiers. Treating all public data as sensitive would make the map less useful and obscure documented lawful releases.
