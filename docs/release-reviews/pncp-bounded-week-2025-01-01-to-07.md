# PNCP bounded-week release review

## Candidate

The candidate contains seven publication windows from 2025-01-01 through 2025-01-07 for modality 6. It has 1,979 reconciled records per release layer and a passed privacy audit. Its local manifest is recorded in [the bounded-week evidence](../evidence/pncp-historical-week-2025-01-01-to-07.md).

## Source-access evidence

The official PNCP open-data page describes public access without registration and states that people can download data for use in applications. The official PNCP FAQ says that contracting data access is public and universal and that the portal adopts open-data formats. These statements support automated retrieval and local analytical use of the public consultation route.

## Distribution decision

**Decision: pending, do not publish to Kaggle.** The reviewed official pages did not provide a dataset-specific redistribution license or a clear grant for republishing this derived Parquet package. The Creative Commons notice found in a site image page applies to that site content and does not establish a license for the procurement dataset.

Before publication, the release owner must locate and record a source-specific license or written redistribution permission, confirm current terms, inspect the selected fields, and attach the final Kaggle version URL to the distribution profile. Public accessibility alone does not satisfy this release gate.
